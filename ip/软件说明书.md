# EvoMax-Enhanced 抗体突变智能筛选软件 V1.0 软件说明书

## 1. 软件概述

EvoMax-Enhanced 是面向抗体候选突变计算筛选的软件。软件读取野生型抗体序列、已有候选突变库和匹配的结构文件，调用蛋白语言模型与结构逆折叠模型进行批量评分，经稳健归一化和加权融合后输出候选排序结果。

本版本支持在 Linux GPU 集群的 SLURM 作业环境运行。项目专属抗体序列、候选库、结构和结果不随公开代码发布。输出结果属于计算推荐，不等同于实验结合力或药效结论。

## 2. 运行环境

- 操作系统：Linux
- Python：3.10
- GPU运行时：CUDA-enabled PyTorch、fair-esm
- 推荐队列：`hp_a800`
- 作业方式：SLURM `sbatch`
- 项目环境文件：`environment.yml`
- 预训练权重：置于项目目录之外，并由配置或脚本路径引用

## 3. 功能模块

1. 输入管理：读取 FASTA、候选突变 CSV 和结构坐标文件。
2. 序列模型评分：使用 ESM-2 对候选位置进行掩码推理，计算突变相对野生型残基的评分。
3. 结构链映射：将 scFv 位置映射至轻链或重链，核对结构链与 WT 序列逐残基一致。
4. 结构逆折叠评分：使用 ESM-IF1 对结构条件下的候选氨基酸替换评分。
5. 稳健融合：对各评分通道按中位数和四分位距进行归一化，再按权重合并。
6. 结果追溯：保存候选编号、突变定义、原始分数、融合分数、模型权重路径和作业信息。

## 4. 集群操作

在服务器项目目录中，使用私有数据配置输入路径后，通过 SLURM `sbatch`
提交任务。公开仓库不包含具体抗体输入、候选突变或结果文件。

## 5. 评分说明

无实验标签时，序列模型和结构模型按 0.65 与 0.35 的权重进行模型-only融合。组合突变使用组成单点突变评分的加和近似。若输入库存在经过确认的实验标签，可在独立校准和验证后增加回归通道；本版本没有虚构或补填 GPR 标签。

## 6. 异常处理与质量控制

- 模型权重不存在时终止任务并报告路径。
- 结构链序列与 WT 不一致时终止对应评分，避免链错配。
- 输入序列长度不一致时拒绝该候选。
- 作业失败时依据 SLURM 作业号、状态、退出码和日志定位原因。
- 第三方模型权重、库和兼容性补丁不作为本软件原创源代码提交。

## 7. 版本与证据边界

软件版本：V1.0。运行记录应保存在受控的私有数据目录。运行证明流程可执行，不证明候选在实验中具有更高亲和力；正式研究结论仍需实验验证。
